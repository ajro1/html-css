## HTML, CSS e JavaScript

ㅤAmbos são essenciais na criação de sites, porém, não são linguagens de programação, e sim recursos usados por desenvolvedores.

### HTML

>ㅤO HTML sigla para _HyperText Markup Language_, é uma linguagem focada na estrutura e no conteúdo de uma página web. 

Ele utiliza "marcas" ou "tags", como;
- `<h1>` para títulos  
- `<p>`para parágrafos definindo elementos como textos, imagens e tabelas.

### CSS
>ㅤO CSS, sigla para _Cascading Style Sheets_, é a linguagem responsável por toda a apresentação visual do conteúdo. Ele define cores, fontes, tamanhos, posicionamento e outros aspectos de design, tornando os sites visualmente atraentes.

ㅤO CSS funciona através de "seletores" que aplicam "declarações" aos elementos HTML. Por exemplo, é possível definir a cor e o tamanho da fonte de um título.

### JavaScript

ㅤEm contraste aos outros exemplos, o JavaScript é uma linguagem de programação. Ela é responsável por adicionar interatividade e dinamismo às páginas web, permitindo a criação de menus interativos, animações e outras funcionalidades que respondem às ações de um possível usuário.


ㅤAo fazer a junção desses três componentes citados, HTML para o conteúdo, CSS  para o estilo, e JavaScript para a interatividade o desenvolvimento do site web, o resultado é um site muito bem personalizado, dinâmico e visualmente agradável.
